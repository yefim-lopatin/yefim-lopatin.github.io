# Правила доставки проекта

- Целевая среда проекта: https://yefim-lopatin.github.io/excalidraw/.
- После выполнения запрошенного изменения и успешного прохождения проверок автоматически добавлять в staging только файлы текущей задачи, создавать содержательный commit и отправлять его в `origin/main`.
- После push дожидаться завершения workflow GitHub Pages и проверять, что опубликованный сайт содержит новый commit. Работу считать завершённой только после успешной публикации.
- Не запрашивать отдельное подтверждение на staging, commit и push для обычной доставки изменений этого проекта.
- Не включать в commit чужие или несвязанные изменения. Остановиться и запросить решение только при конфликте изменений, обнаружении секретов, расхождении истории, неуспешных проверках или необходимости разрушительного действия.
