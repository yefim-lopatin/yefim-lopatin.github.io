# Хранение досок на сервере друга

Сервис принимает зашифрованные доски и изображения по `/api/boards/`. Ключ расшифровки остаётся в браузере. Для доступа браузер передаёт отпечаток номера комнаты и её ключа. Секретные ссылки и ключи в журнал не записываются. Перечисление и удаление досок через этот сервис не предусмотрены.

Контейнер `excalidraw-storage` работает в сети `excalidraw-history-network`, без открытого наружу порта. Постоянная папка `/home/elmif/excalidraw-deploy/board-storage/data` подключается как `/data`. При обновлении контейнера эту папку сохраняют. В резервные копии нужно включать всю папку `data`.

Доска записывается через временный файл с принудительной записью на диск и атомарной заменой. Предыдущая версия остаётся в `scene.previous`. Проверка версии отклоняет устаревшую запись; браузер читает новую версию, объединяет изменения участников и повторяет сохранение. Максимальный размер одного запроса — 256 МиБ. Общий объём ограничен свободным местом на сервере.

В сборке сайта задано `VITE_APP_BOARD_STORAGE_URL=/api/boards`. Если сервер ещё не содержит доску, приложение читает старую копию из Firebase и переносит её. Старые изображения копируются при загрузке. Старые данные Firebase не удаляются и не перезаписываются. После переноса существующая серверная копия имеет приоритет; при недоступности сервера приложение сообщает об ошибке, а не подменяет её устаревшей копией.

Сохранение повторяется каждые 20 секунд при открытой комнате и наличии сети. Неудачная загрузка изображения не отмечается как успешная. Перед закрытием вкладки браузер предупреждает о незавершённой загрузке. Для перехода на новую версию всем участникам нужно обновить вкладки, предварительно сохранив несохранённую работу в файл `.excalidraw`.

Для запуска:

```sh
docker build -t excalidraw-storage:VERSION services/board-storage
mkdir -p /home/elmif/excalidraw-deploy/board-storage/data
sudo chown 1000:1000 /home/elmif/excalidraw-deploy/board-storage/data
docker run -d --name excalidraw-storage --restart unless-stopped \
  --network excalidraw-history-network \
  -v /home/elmif/excalidraw-deploy/board-storage/data:/data \
  excalidraw-storage:VERSION
```

Файл `nginx.conf` добавляет маршрут сервиса и сохраняет маршрут истории бросков. До замены конфигурации нужно сохранить резервную копию, затем выполнить `docker exec excalidraw-site nginx -t` и `docker exec excalidraw-site nginx -s reload`. Проверка сервиса внутри контейнера: `fetch('http://127.0.0.1:3004/health')`.
