# Прямой доступ Codex к доскам Excalidraw

Сервис подключается к серверу совместной работы через Socket.IO и обменивается сообщениями AES-128-GCM по протоколу Excalidraw. Браузер и управление вкладкой для работы сервиса не нужны. Интерфейс сайта не изменяется.

## Доступ из Codex

```sh
codex mcp add friend-excalidraw --env "SSH_AUTH_SOCK=$SSH_AUTH_SOCK" -- /usr/bin/ssh -T -o BatchMode=yes -o ConnectTimeout=10 elmif@159.69.159.241 docker exec -i excalidraw-mcp node /app/proxy.mjs
```

После добавления откройте новый чат Codex, чтобы он получил инструменты MCP. Сервис работает постоянно; закрытие чата не отключает его от досок. SSH использует уже настроенный ключ пользователя. Дополнительные публичные порты, общедоступные ссылки на MCP и пароли в репозитории не требуются. Процесс MCP слушает только `127.0.0.1:3003` внутри контейнера, без публикации порта. `proxy.mjs` передаёт MCP JSON-RPC между стандартным вводом/выводом SSH и сервисом.

`SSH_AUTH_SOCK` передаётся явно, чтобы Codex мог использовать текущий SSH-агент. Если после перезагрузки компьютера путь агента изменится, повторите команду подключения.

## Инструменты

- `list_boards`: список досок, состояние связи и готовность данных.
- `connect_board`: регистрация ссылки совместной работы именно с сервера друга.
- `create_board`: новая пустая комната и её ссылка.
- `read_board`: чтение элементов порциями, включая текст, координаты и связи.
- `edit_board`: добавление фигур, отдельных надписей, линий и стрелок; изменение положения, размеров, текста и оформления; удаление элементов.
- `list_snapshots` и `restore_snapshot`: снимки перед правками и восстановление.
- `export_board`: JSON сцены в формате `.excalidraw`, без байтов изображений.

Перед `edit_board` и `restore_snapshot` нужно прочитать доску и передать её `revision` как `expectedRevision`. Если данные уже изменились, операция отклоняется. Это защищает от устаревшего состояния на момент вызова, но не блокирует правки другого участника, сделанные одновременно в его браузере. Такие изменения объединяются по версии элемента и `versionNonce`, как в Excalidraw. Снимок сохраняется до каждого пакета правок. Восстановление всей доски отменяет также более поздние изменения других участников.

При первом подключении существующей комнаты один её участник должен быть онлайн и передать начальную сцену. Пока она не получена, чтение и изменения заблокированы: пустая комната не считается пустой доской. После получения сцена хранится на диске и доступна без браузера, в том числе после перезапуска. Сервис не восстанавливает изменения, сделанные во время его отключения, если их нет ни у одного подключённого участника: существующий сервер комнат лишь пересылает сообщения и не хранит историю.

Изображения читаются как элементы с `fileId`, без самих картинок. Снимки и экспорт не являются полной резервной копией изображений. Точные размеры новых надписей браузер пересчитывает своим шрифтом; сервис задаёт приближённые. Сложные изменения связанных подписей, привязанных стрелок и рамок ограничены, чтобы не повредить связи. Новые стрелки самостоятельные, без привязки к фигурам. Результат изменения означает сохранение на сервере и отправку в комнату; сервер пересылки не подтверждает доставку каждому отдельному участнику.

## Размещение

Из этой папки:

```sh
docker build -t excalidraw-mcp:VERSION .
docker volume create excalidraw-mcp-data
docker run -d --name excalidraw-mcp --restart unless-stopped \
  --mount source=excalidraw-mcp-data,target=/data \
  --read-only --tmpfs /tmp --cap-drop ALL --security-opt no-new-privileges \
  excalidraw-mcp:VERSION
```

Контейнер запускается от пользователя `node`. Реестр досок содержит секретные ключи комнат и создаётся с правами `0600`, каталог данных — `0700`. Сцены и снимки шифруются ключом комнаты; ключи доступны самому сервису и администраторам сервера. Не публикуйте реестр, том данных и ссылки комнат. Снимки сохраняются без автоматического удаления; свободное место нужно учитывать.

Проверка состояния без браузера:

```sh
ssh elmif@159.69.159.241 docker exec excalidraw-mcp node -e \
  'fetch("http://127.0.0.1:3003/health").then(r=>r.json()).then(console.log)'
```

Для резервного копирования остановите сервис, скопируйте целиком том `excalidraw-mcp-data` и запустите сервис снова. Том содержит ключи; храните резервную копию с теми же ограничениями доступа.

## Проверка изменений

Проверьте синтаксис трёх файлов через `node --check`. Через официальный MCP клиент создайте тестовую доску, прочитайте её, добавьте элемент, измените его, проверьте отказ устаревшей версии и восстановите снимок. Независимым клиентом Socket.IO проверьте получение и отправку AES-GCM сообщений. После перезапуска контейнера повторите чтение доски, проверьте отсутствие опубликованных портов и отказ на запросы с браузерным `Origin`. Не изменяйте пользовательскую доску для проверки соединения.
