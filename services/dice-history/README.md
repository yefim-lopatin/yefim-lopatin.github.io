# История бросков

Отдельный сервис Node.js хранит записи вне доски. Комната определяется отпечатком ссылки, включая её секретный ключ; сама ссылка сервису не передаётся. Без комнаты используется отдельная история браузера.

Записи сохраняются в подключённой папке `/data`. При первом запуске создаётся `/data/owner-key` с правами 600. Ключ не включается в сайт или Git. В комментариях ведущий вводит его через «Доступ ведущего». Сервер проверяет ключ при каждой очистке; имя игрока прав доступа не даёт. Ключ хранится в браузере только до конца сеанса вкладки.

На сервере контейнер `excalidraw-history` и существующий `excalidraw-site` подключены к сети `excalidraw-history-network`. Файл `nginx.conf` добавляет маршрут `/api/dice-history` к сервису; остальные запросы продолжают обслуживаться сайтом. Публичный отдельный порт не нужен.

Очистка относится только к истории текущей комнаты и не меняет доску. Записи появляются у участников в течение трёх секунд. Резервная копия должна включать папку данных истории.
